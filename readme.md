# OrbitAlert 🛰️

Sistema de alerta de tempestades solares em tempo real, desenvolvido pela equipe Debuggers para a Global Solution 2026 da FIAP.

## Sobre o projeto

O OrbitAlert utiliza a API DONKI da NASA para monitorar eventos de clima espacial e avisar usuários quando o Sol ameaça a tecnologia da Terra.

## Tecnologias

- HTML5, CSS3 e JavaScript puro
- API NASA DONKI
- Python (modelagem matemática)
- Arduino / Edge Computing

## Funcionalidades

- Landing page com 6 seções de conteúdo
- Slideshow interativo com 3 slides
- Formulário de contato com validação
- Quiz com 10 perguntas sobre clima espacial
- 3 temas de cor (Escuro, Nebula, Galáxia)
- Canvas animado com estrelas
- Menu responsivo com hamburguer
- Scroll reveal nas seções
